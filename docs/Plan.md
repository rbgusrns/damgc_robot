# 다중 소형 로봇 기반 재난 탐색 및 협동 구호물품 운반 시스템 개발 계획서

> 이 문서는 2026년 7월 13일~9월 14일의 **기준 계획(baseline)** 이다.
> 구현 완료 여부와 현재 우선순위는 [개발 현황 및 로드맵](STATUS_AND_ROADMAP.md)에서
> 관리하며, 상세 실험 근거는 `docs/progress/`와 각 ROS 패키지의 `docs/`에 기록한다.

## 1. 프로젝트 개요

### 1.1 프로젝트명

**RGB-D 기반 3차원 재난 환경 탐색 및 다중 로봇 협동 구호물품 운반 시스템**

### 1.2 개발 기간

* 개발 시작: 2026년 7월 13일
* 발표 예정: 2026년 9월 14일
* 총 개발 기간: 약 9주
* 개발 인원: 6명

### 1.3 개발 배경

재난 현장에서는 붕괴 위험, 좁은 통로, 장애물 등으로 인해 구조 인력이 현장 내부에 즉시 진입하기 어렵다. 소형 이동로봇을 활용하면 구조 인력보다 먼저 현장을 탐색하고 공간 정보를 확보할 수 있으며, 생존자의 위치를 파악한 뒤 물이나 응급물품을 전달하는 임무도 수행할 수 있다.

그러나 하나의 소형 로봇은 크기와 구동력의 제약으로 인해 운반할 수 있는 물품의 무게가 제한된다. 본 프로젝트에서는 한 대의 로봇이 단독으로 물품을 운반하거나, 물품의 크기와 무게에 따라 두 대의 로봇이 협동하여 운반할 수 있는 다중 로봇 시스템을 구현한다.

## 2. 개발 목표

### 2.1 최종 목표

소형 로봇 2대를 이용하여 모의 재난 환경을 탐색하고, Intel RealSense D435 RGB-D 카메라로 3차원 지도를 생성하며, 생존자의 위치를 탐지한 뒤 구호물품을 단독 또는 협동 방식으로 전달하는 시스템을 개발한다.

### 2.2 세부 목표

1. RealSense D435를 이용한 실시간 3차원 환경 지도 생성
2. Visual SLAM을 이용한 탐색 로봇의 위치 및 자세 추정
3. BNO055 IMU와 wheel odometry를 활용한 자세 및 주행 상태 보정
4. 카메라 영상 기반 생존자 탐지
5. Depth 정보를 활용한 생존자의 3차원 위치 계산
6. Nav2 기반 탐색 로봇의 자율주행
7. AprilTag 기반 구호물품 위치 인식 및 정밀 접근
8. 그리퍼를 이용한 구호물품 파지
9. 경량 물품의 단독 운반
10. 중량 물품의 다중 로봇 협동 운반
11. 지도, 생존자 위치, 로봇 상태를 확인할 수 있는 시각화 시스템 구현

### 2.3 개발 범위 제한

발표일까지의 안정적인 구현을 위해 다음 기능은 우선 개발 범위에서 제외한다.

* 로봇 3대 이상의 군집 운용
* 각 로봇의 3차원 지도 자동 병합
* 임의 형상 물체에 대한 범용 파지
* 계단 및 대형 잔해 극복
* 실제 연기 및 먼지 환경에서의 탐색
* 강화학습 기반 협동제어
* 완전 분산형 임무 할당
* 자체 객체 탐지 모델 학습

## 4. 하드웨어 구성

### 4.1 이동 플랫폼

* 로봇 수량: 2대
* 구동 방식: 2륜 차동 조향
* 보조 지지: 캐스터 휠 또는 볼 캐스터
* 바퀴: 일반 고무 바퀴
* 모터: 엔코더 내장 DC 기어드 모터 2개
* 제어 방식: 좌우 바퀴 속도 폐루프 제어
* 차체 크기: 약 15~20cm급
* 운반 물품: 직육면체의 구급함

4륜 차동구동보다 구조가 단순한 2륜 차동 조향을 사용하여 제작 난이도와 제어 복잡도를 낮춘다. 후방 또는 전방에 캐스터를 배치하여 차체를 지지하고, 좌우 바퀴 속도 차이를 이용해 직진, 회전 및 제자리 회전을 수행한다.

### 4.2 주요 센서 및 컴퓨팅 보드

* 상위 제어기: Jetson Orin 2대
* RGB-D 카메라: Intel RealSense D435
* IMU: BNO055
* 하위 제어기: STM32G474VET6
* 주행 피드백: 모터 엔코더 기반 wheel odometry

Jetson Orin 2대를 사용하여 두 로봇의 운영체제, ROS 2 버전, 빌드 환경 및 패키지 구조를 통일한다. RealSense D435는 RGB 영상과 depth 영상을 제공하며, BNO055는 yaw 및 자세 정보를 제공하여 odometry와 로봇 상태 추정에 활용한다.

### 4.3 그리퍼

* 위치 오차 흡수를 위한 고무 부싱 또는 회전 유격 구조

### 4.4 규격 구호물품

안정적인 반복 시연을 위해 자유 형상 물체가 아닌 전용 구호물품을 제작한다.

구호물품에는 다음 요소를 적용한다.

* AprilTag
* 그리퍼 이탈을 방지하는 턱
* 경량 및 중량 물품 구분용 태그 ID
* 무게중심을 중앙에 배치한 구조

### 4.5 전원 구성

* 고출력 DC-DC 컨버터

## 5. 소프트웨어 구성

### 5.1 공통 개발환경

두 로봇 모두 Jetson Orin을 사용하므로 가능한 한 동일한 개발환경을 적용한다.

* JetPack 6.2.2
* Ubuntu 22.04
* ROS 2 Humble
* colcon 기반 ROS 2 workspace
* RealSense ROS driver
* BNO055 ROS driver 또는 사용자 정의 BNO055 bridge node
* robot_localization
* Nav2
* RViz2 또는 Foxglove
* Git 기반 형상관리

### 5.2 탐색 로봇 소프트웨어

* RealSense D435 카메라 드라이버
* Isaac ROS Visual SLAM
* nvblox
* robot_localization
* Nav2
* 객체 탐지 모델
* AprilTag 인식
* RViz2 또는 Foxglove
* 사용자 정의 임무 관리 노드
* 사용자 정의 협동 운반 제어 노드

### 5.3 주요 데이터 흐름

RealSense D435에서 획득한 RGB 영상과 depth 영상은 생존자 탐지, AprilTag 인식 및 3차원 지도 생성에 사용된다. Visual SLAM은 카메라 영상과 로봇 좌표계를 이용하여 로봇의 위치와 자세를 추정하고, depth 영상과 추정된 카메라 자세는 nvblox에 입력되어 3차원 voxel 및 mesh 지도를 생성한다.

BNO055 IMU와 wheel odometry는 robot_localization에 입력되어 `odom → base_link` 기준의 주행 상태 추정을 보조한다. RGB 영상에서 생존자를 탐지한 뒤, 탐지 영역 내부의 depth 값을 이용하여 생존자의 카메라 기준 3차원 위치를 계산한다. 계산된 위치는 ROS TF를 통해 지도 좌표계로 변환하고 RViz2 또는 Foxglove에 표시한다.

Nav2는 생성된 주행용 지도와 로봇 위치를 이용하여 목표 경로를 생성하고, STM32 하위 제어기에 속도 명령을 전달한다.

### 5.4 보조 로봇 소프트웨어

보조 로봇도 Jetson Orin과 ROS 2 Humble을 사용한다. 보조 로봇은 리더 로봇과 같은 개발환경을 사용하지만, 연산량이 큰 3차원 지도 생성과 생존자 탐지는 기본 임무에서 제외하고 협동 운반에 필요한 기능을 중심으로 실행한다.

* ROS 2 기반 리더-팔로워 통신
* STM32와의 UART 통신
* 목표 속도 수신 및 전달
* 로봇 상태 및 배터리 정보 전송
* 그리퍼 명령 전달
* AprilTag 기반 상대 위치 보정
* BNO055 yaw 및 wheel odometry 송신

### 5.5 STM32 하위 제어

STM32는 다음과 같은 고주기 실시간 제어를 담당한다.

* 모터 속도 PID 제어
* 엔코더 계수
* 2륜 차동구동 wheel odometry 계산
* BNO055 IMU 데이터 수집 또는 상위 제어기 전달
* 그리퍼 모터 제어
* 리미트 스위치 및 범퍼 입력

### 5.6 통신 인터페이스

#### Orin-Orin 통신

두 로봇 모두 ROS 2 환경을 사용하므로 리더와 팔로워 간 통신은 ROS 2 topic, service, action을 기본으로 한다.

* `/leader/cmd_vel`: 리더 로봇 속도 명령
* `/follower/cmd_vel`: 팔로워 로봇 속도 명령
* `/leader/odom`: 리더 로봇 odometry
* `/follower/odom`: 팔로워 로봇 odometry
* `/leader/imu`: 리더 BNO055 IMU
* `/follower/imu`: 팔로워 BNO055 IMU
* `/follower/status`: 팔로워 상태, 배터리, 그리퍼, fault 정보
* `/cooperation/state`: 협동 운반 상태
* `/cooperation/target_velocity`: 협동 운반용 공통 속도 명령
* `/mission/state`: 전체 임무 상태


#### Orin-STM32 통신

Jetson Orin과 STM32 사이의 통신은 UART를 사용한다.

* 상위 제어기에서 STM32로 전달: 좌우 바퀴 목표 속도, 그리퍼 명령
* STM32에서 상위 제어기로 전달: 엔코더, 좌우 바퀴 속도, BNO055 yaw, 그리퍼 상태
* 제어 주기: 속도 명령 50Hz, 상태 보고 50Hz

## 6. 임무 수행 시나리오

### 6.1 환경 탐색

탐색 로봇이 모의 재난 공간을 이동하며 실시간으로 3차원 지도를 생성한다. 지도와 로봇의 현재 위치는 RViz2 또는 별도의 모니터링 화면에 표시한다.

### 6.2 생존자 탐지

카메라 영상에서 사람 또는 마네킹을 탐지하고 depth 정보를 결합하여 생존자의 위치를 계산한다. 계산된 위치를 지도상에 마커로 표시하고 임무 관리자에 전달한다.

### 6.3 물품 선택

구호물품의 AprilTag ID를 이용하여 경량 물품과 중량 물품을 구분한다.

* 경량 물품: 탐색 로봇이 단독 운반
* 중량 물품: 보조 로봇을 호출하여 협동 운반

### 6.4 물품 접근 및 파지

로봇은 Nav2를 이용하여 물품 주변의 사전 접근 지점까지 이동한다. 최종 접근 구간에서는 AprilTag 기반 상대 위치를 이용하여 저속으로 정렬한 후 그리퍼를 닫는다.

### 6.5 협동 운반

두 로봇이 물품의 양쪽 손잡이를 각각 잡는다. 탐색 로봇이 리더가 되어 목표 속도와 회전 속도를 생성하고, 보조 로봇은 해당 명령을 추종한다.

협동 운반 중에는 다음 정보를 활용한다.

* 두 로봇의 좌우 바퀴 속도
* 엔코더 odometry
* BNO055 yaw
* 상대 거리와 각도
* 그리퍼 상태
* 모터 전류 또는 파지 하중

### 6.6 물품 전달

생존자 위치 또는 생존자 근처의 배송 지점까지 이동한 후 구호물품을 내려놓고 임무 완료 상태를 전송한다.

## 12. 최종 발표 구성

### 시연 1: 3차원 재난 지도 생성

탐색 로봇이 공간을 이동하며 실시간으로 3차원 지도를 생성한다.

### 시연 2: 생존자 탐지

사람 또는 마네킹을 탐지하고 지도상에 생존자 위치를 표시한다.

### 시연 3: 단독 물품 운반

탐색 로봇이 경량 물품을 인식하고 단독으로 생존자 위치까지 운반한다.

### 시연 4: 협동 물품 운반

중량 물품을 인식하면 보조 로봇을 호출하고 두 로봇이 물품을 협동 운반한다.

실시간 시연 실패에 대비하여 각 기능과 전체 시나리오의 정상 동작 영상을 사전에 촬영한다.

## 13. 기대 효과 및 차별점

본 프로젝트는 단순히 SLAM을 이용해 지도를 생성하는 데 그치지 않고, 환경 인지 결과를 실제 임무 수행과 연결한다는 점에서 차별성을 가진다.

주요 차별점은 다음과 같다.

1. RealSense D435 기반 실시간 3차원 재난 환경 지도 생성
2. 생존자 탐지 결과의 지도 좌표화
3. 물품 특성에 따른 단독 및 협동 운반 방식 선택
4. Jetson Orin 2대를 사용한 동종 로봇 개발환경 통일
5. Jetson 기반 상위 인지와 STM32 기반 실시간 하위 제어의 분산 구조
6. 2륜 차동 조향 기반의 단순하고 구현 가능한 소형 이동 플랫폼
7. 인지, 자율주행, 물체 파지 및 협동제어가 연결된 통합 임무 구현

이를 통해 다중 로봇이 각자의 연산 능력과 구동력을 활용하여 단일 로봇의 한계를 보완하는 재난 대응 시스템의 가능성을 제시한다.
