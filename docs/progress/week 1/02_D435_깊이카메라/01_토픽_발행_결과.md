# D435 깊이카메라 1 — 토픽 발행 결과

## 1. 작업 목적

Jetson에서 Intel RealSense D435 카메라를 인식하고, ROS 2 Humble 환경에서 컬러 영상과 뎁스 영상을 토픽으로 발행한 과정을 정리한 문서이다.

이 문서는 실제로 입력한 명령어의 의미와 실행 결과를 중심으로 정리하였다.

---

## 2. 개발 환경 확인

### 입력한 명령어

```bash
echo "ROS_DISTRO=$ROS_DISTRO"
ls /opt/ros
which ros2
which roscore
lsusb
```

### 명령어 의미

#### `echo "ROS_DISTRO=$ROS_DISTRO"`

현재 터미널에 설정된 ROS 배포판 이름을 확인하는 명령어이다.

실행 결과:

```text
ROS_DISTRO=humble
```

현재 사용 중인 ROS 버전이 ROS 2 Humble임을 확인하였다.

---

#### `ls /opt/ros`

컴퓨터에 설치된 ROS 배포판 목록을 확인하는 명령어이다.

실행 결과:

```text
humble
```

Jetson의 `/opt/ros` 경로에 ROS 2 Humble이 설치되어 있음을 확인하였다.

---

#### `which ros2`

`ros2` 명령어가 설치된 위치를 확인하는 명령어이다.

실행 결과:

```text
/opt/ros/humble/bin/ros2
```

ROS 2 명령어가 정상적으로 설치되어 있으며, ROS 2 Humble 경로에서 실행되고 있음을 확인하였다.

---

#### `which roscore`

`roscore` 명령어의 설치 위치를 확인하는 명령어이다.

실행 결과는 출력되지 않았다.

`roscore`는 ROS 1에서 사용하는 명령어이며, ROS 2에서는 별도의 ROS Master를 실행하지 않기 때문에 출력되지 않아도 문제가 없다.

---

#### `lsusb`

Jetson의 USB 포트에 연결된 장치 목록을 확인하는 명령어이다.

실행 결과 중 카메라 관련 항목:

```text
Bus 001 Device 004: ID 8086:0b07 Intel Corp. RealSense D435
```

Intel RealSense D435가 Jetson의 USB 장치로 정상 인식되고 있음을 확인하였다.

---

## 3. RealSense 카메라 노드 실행

### 입력한 명령어

```bash
ros2 launch realsense2_camera rs_launch.py
```

### 명령어 의미

- `ros2 launch`  
  ROS 2의 launch 파일을 실행하는 명령어이다.

- `realsense2_camera`  
  Intel RealSense 카메라를 ROS 2에서 사용하기 위한 패키지 이름이다.

- `rs_launch.py`  
  RealSense 카메라 노드와 필요한 설정을 함께 실행하는 launch 파일이다.

이 명령어를 실행하면 RealSense D435에서 컬러 영상과 뎁스 영상을 받아 ROS 2 토픽으로 발행한다.

---

## 4. 카메라 실행 결과 해석

### RealSense ROS 및 라이브러리 버전

```text
RealSense ROS v4.58.2
Built with LibRealSense v2.58.2
Running with LibRealSense v2.58.2
```

RealSense ROS 패키지 버전은 `4.58.2`이며, 빌드 및 실행에 사용된 LibRealSense 버전은 `2.58.2`이다.

빌드 버전과 실행 버전이 동일하므로 라이브러리 버전 불일치 문제는 확인되지 않았다.

---

### RealSense 장치 검색 결과

```text
Device with serial number 109622073868 was found.
Device with name Intel RealSense D435 was found.
```

ROS 2 RealSense 노드가 연결된 카메라를 정상적으로 검색하였다.

확인된 장치:

```text
장치 이름: Intel RealSense D435
시리얼 번호: 109622073868
```

---

### 카메라 펌웨어 정보

```text
Device FW version: 5.13.0.50
```

현재 연결된 RealSense D435의 펌웨어 버전은 `5.13.0.50`이다.

---

### 뎁스 영상 설정

```text
Set ROS param depth_module.depth_profile to default: 640x480x15
Open profile: stream_type: Depth(0), Format: Z16, Width: 640, Height: 480, FPS: 15
```

뎁스 영상은 다음 설정으로 실행되었다.

| 항목 | 설정 |
|---|---|
| 해상도 | 640×480 |
| 프레임 속도 | 15 FPS |
| 데이터 형식 | Z16 |

`Z16`은 각 픽셀에 16비트 깊이값이 저장되는 형식이다. 각 픽셀값은 카메라와 물체 사이의 거리를 나타내는 데 사용된다.

---

### 컬러 영상 설정

```text
Set ROS param rgb_camera.color_profile to default: 640x480x15
Open profile: stream_type: Color(0), Format: RGB8, Width: 640, Height: 480, FPS: 15
```

컬러 영상은 다음 설정으로 실행되었다.

| 항목 | 설정 |
|---|---|
| 해상도 | 640×480 |
| 프레임 속도 | 15 FPS |
| 데이터 형식 | RGB8 |

`RGB8`은 빨강, 초록, 파랑 값을 각각 8비트로 표현하는 일반적인 컬러 영상 형식이다.

---

### 카메라 노드 실행 완료

```text
RealSense Node Is Up!
```

이 메시지는 RealSense 카메라 노드가 정상적으로 실행되었음을 의미한다.

이 상태에서 컬러 영상과 뎁스 영상 관련 ROS 2 토픽이 계속 발행된다.

---

## 5. 실행 중 출력된 경고 해석

### 설정 파일 관련 경고

```text
No valid configuration file found at :
/home/maze/.realsense-config.json loading defaults
```

별도의 RealSense 설정 파일을 찾지 못해 기본 설정을 사용한다는 뜻이다.

카메라 실행 실패를 의미하지 않으며, 실제로 기본 설정으로 카메라가 정상 실행되었다.

---

### USB 연결 관련 경고

```text
Device USB type: 2.1
Device 109622073868 is connected using a 2.1 port.
Reduced performance is expected.
```

RealSense D435가 USB 2.1 방식으로 연결되어 있음을 의미한다.

USB 대역폭이 낮기 때문에 높은 해상도나 높은 프레임 속도를 사용할 때 성능이 제한될 수 있다. 현재 설정인 640×480, 15 FPS에서는 영상 토픽이 정상적으로 발행되었다.

---

### 전원 주파수 설정 관련 경고

```text
Could not set param: rgb_camera.power_line_frequency with 3
Range: [0, 2]
```

컬러 카메라의 전원 주파수 옵션에 허용 범위를 벗어난 값이 요청되어 해당 설정을 적용하지 못했다는 뜻이다.

이 경고가 출력되었지만 컬러 영상과 뎁스 영상 스트림은 정상적으로 실행되었다.

---

## 6. 발행된 카메라 토픽 확인

### 입력한 명령어

```bash
source /opt/ros/humble/setup.bash
ros2 topic list | grep camera
```

### 명령어 의미

#### `source /opt/ros/humble/setup.bash`

현재 터미널에서 ROS 2 Humble 명령어와 환경변수를 사용할 수 있도록 설정을 불러오는 명령어이다.

#### `ros2 topic list`

현재 ROS 2 시스템에서 생성된 전체 토픽 목록을 출력한다.

#### `| grep camera`

전체 토픽 중 이름에 `camera`가 포함된 항목만 골라 출력한다.

---

## 7. 확인된 주요 토픽

### 컬러 영상 관련 토픽

```text
/camera/camera/color/camera_info
/camera/camera/color/image_raw
/camera/camera/color/image_raw/compressed
/camera/camera/color/image_raw/compressedDepth
/camera/camera/color/image_raw/theora
/camera/camera/color/metadata
```

#### `/camera/camera/color/image_raw`

RealSense D435의 원본 컬러 영상이 발행되는 토픽이다.

#### `/camera/camera/color/camera_info`

컬러 카메라의 해상도, 초점거리, 카메라 행렬 등 카메라 내부 정보를 발행하는 토픽이다.

#### `compressed`, `theora`

원본 컬러 영상을 압축된 형태로 전송하기 위한 토픽이다.

#### `/camera/camera/color/metadata`

컬러 영상의 프레임 번호, 노출 등 부가 정보를 포함하는 토픽이다.

---

### 뎁스 영상 관련 토픽

```text
/camera/camera/depth/camera_info
/camera/camera/depth/image_rect_raw
/camera/camera/depth/image_rect_raw/compressed
/camera/camera/depth/image_rect_raw/compressedDepth
/camera/camera/depth/image_rect_raw/theora
/camera/camera/depth/metadata
```

#### `/camera/camera/depth/image_rect_raw`

보정된 원본 뎁스 영상이 발행되는 핵심 토픽이다.

이 영상의 각 픽셀에는 카메라와 물체 사이의 깊이값이 저장된다.

#### `/camera/camera/depth/camera_info`

뎁스 카메라의 해상도, 카메라 행렬 등 내부 정보를 발행하는 토픽이다.

#### `/camera/camera/depth/metadata`

뎁스 영상의 프레임과 관련된 부가 정보를 발행하는 토픽이다.

---

### 카메라 좌표 관계 관련 토픽

```text
/camera/camera/extrinsics/depth_to_color
/camera/camera/extrinsics/depth_to_depth
```

뎁스 카메라 좌표계와 컬러 카메라 좌표계 사이의 위치 및 회전 관계를 나타내는 외부 파라미터 관련 토픽이다.

---

## 8. 뎁스 토픽 발행 주기 확인

### 입력한 명령어

```bash
ros2 topic hz /camera/camera/depth/image_rect_raw
```

### 명령어 의미

지정한 토픽이 초당 몇 번 발행되는지 측정하는 명령어이다.

여기서는 뎁스 영상 토픽인 다음 항목의 실제 발행 주기를 확인하였다.

```text
/camera/camera/depth/image_rect_raw
```

---

## 9. 발행 주기 측정 결과

실행 직후 다음 경고가 출력되었다.

```text
WARNING: topic [/camera/camera/depth/image_rect_raw] does not appear to be published yet
```

명령어를 실행한 직후에는 아직 첫 번째 메시지를 받지 못해 일시적으로 출력된 경고이다.

이후 다음 결과가 반복 출력되었다.

```text
average rate: 13.120
    min: 0.065s max: 0.200s std dev: 0.03441s window: 14

average rate: 13.579
    min: 0.065s max: 0.200s std dev: 0.02694s window: 29

average rate: 13.745
    min: 0.061s max: 0.200s std dev: 0.02401s window: 44

average rate: 14.042
    min: 0.061s max: 0.200s std dev: 0.02090s window: 59
```

### 결과 해석

- 뎁스 영상이 초당 약 13~14회 발행되고 있다.
- 카메라 설정값은 15 FPS이며, 실제 발행 주기는 약 14 Hz로 확인되었다.
- `average rate`가 계속 출력되었으므로 뎁스 영상 데이터가 정상적으로 들어오고 있다.
- USB 2.1 연결과 시스템 처리 상태 때문에 설정값인 15 FPS보다 실제 측정값이 약간 낮게 나타난 것으로 볼 수 있다.

## 10. 영상 화면 확인

### 입력한 명령어

```bash
ros2 run rqt_image_view rqt_image_view
```

### 명령어 의미

ROS 2에서 발행 중인 영상 토픽을 화면으로 확인할 수 있는 `rqt_image_view` 프로그램을 실행하는 명령어이다.

프로그램에서 다음 뎁스 토픽을 선택하였다.

```text
/camera/camera/depth/image_rect_raw
```

실행 결과, RealSense D435의 뎁스 영상이 화면에 정상적으로 표시되는 것을 확인하였다.

## 11. 최종 결과 정리

이번 작업에서 확인한 전체 흐름은 다음과 같다.

```text
Jetson에서 RealSense D435 USB 인식
→ ROS 2 Humble 환경 확인
→ realsense2_camera 노드 실행
→ 컬러 및 뎁스 스트림 시작
→ 카메라 관련 ROS 2 토픽 생성
→ 뎁스 토픽 발행 주기 측정
→ rqt_image_view에서 뎁스 영상 출력 확인
```

최종적으로 다음 항목이 정상 동작하였다.

| 확인 항목 | 결과 |
|---|---|
| RealSense D435 USB 인식 | 정상 |
| ROS 2 Humble 환경 | 정상 |
| RealSense 카메라 노드 실행 | 정상 |
| 컬러 영상 토픽 발행 | 정상 |
| 뎁스 영상 토픽 발행 | 정상 |
| 뎁스 토픽 발행 주기 | 약 13~14 Hz |
| 뎁스 영상 화면 출력 | 정상 |

따라서 Intel RealSense D435의 ROS 2 뎁스카메라 토픽 발행 작업이 정상적으로 완료되었다.
