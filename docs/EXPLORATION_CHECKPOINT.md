# 탐색 후 저장하고 협동운반 재개하기

새 탐색과 저장:

```bash
cd ~/damgc_robot
bash scripts/run_exploration_checkpoint.sh
```

리더를 3×3m 탐색의 원래 시작 위치·방향에 둔다. 초기 회전, 짧은 경유점 탐색,
도착 시 사람 인식, 출발지 복귀, 반대 방향 정렬을 수행한다. **파지 전에** 지도를 HOLD하고
정지 상태를 확인한 뒤 `data/maps/vslam_mapping_날짜_시간/`에 저장한다.
완료 문구 `CHECKPOINT SAVED`가 나와야 저장 성공이다. 파지·운반은 자동 시작하지 않는다.

저장 항목:

- `map.nvblx`: nvblox 지도 레이어
- `survivors.json`: 생존자 ID, 좌표, 확인 횟수와 관측 기록
- `navigation_slice.json`: 같은 odom 좌표계의 운반용 2D 거리 지도
- `manifest.json`: 저장 위치·방향, 원래 출발점, 복귀 완료 기록, 파일 정보
- `projection.pgm/yaml`: 표시용 2D 지도가 수신됐을 때 추가하는 점검용 이미지

마지막 완성본은 `data/maps/latest_mission`으로 연결한다. 지도·좌표 파일을 모두 기록한 뒤
manifest를 원자적으로 확정하므로, 불완전한 저장은 복원 대상으로 인정하지 않는다.
생존자가 없는 탐색도 빈 목록으로 저장할 수 있다.

## 다음 실행에서 불러오기

기존 태스크를 Ctrl-C로 종료하고, 로봇을 **저장 당시 복귀 후 상자를 바라보던 위치·방향**에 맞춘다.
원래 전방을 보는 탐색 시작 자세와 반대 방향이다. 이 기능은 임의 위치에서의 시각 재위치추정이 아니다.

```bash
bash scripts/run_saved_mission.sh
# 특정 저장본을 고르려면:
bash scripts/run_saved_mission.sh /home/maze/damgc_robot/data/maps/vslam_mapping_날짜_시간
```

파일과 좌표계를 먼저 검증하고, EKF odom 초기 상태와 nvblox 지도를 저장본으로 복원한다.
생존자 마커와 좌표를 재게시하며, 관측 기록은 과거 관측으로 표시한다.
지도 HOLD·시각 전역 위치 보정 차단을 확인한 뒤 대기한다.
초기 회전·재탐색·YOLO·파지·주행은 요청하지 않는다. 이어서 기존 협동 파지/곡선 운반 절차를 선택한다.
지도 불러오기 명령 자체가 리더·서브를 자동으로 결합하거나 운반을 활성화하지는 않는다.

집게/하드웨어와 서브 준비는 기존 절차와 같다. 서브를 올바른 배치에 두고 양쪽 준비를 확인한 후
협동운반 터미널에서 활성화한다. 저장 지도는 실시간 후방 장애물 센서가 아니다.

검증: 불완전 파일·좌표계 불일치·잘못된 위치·경로 이탈 파일 거부, 복귀 후 저장만 수행하고
파지 구성요소를 시작하지 않는 감독 절차, 격리된 ROS에서 정지·HOLD 후 지도/생존자 저장을 검사한다.
실물 저장/복원 결과는 해당 세션 로그로 별도 확인한다.
